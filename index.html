About the Project

This webpage presents the assignments completed as part of the Digital Humanities coursework. The project explores the application of Natural Language Processing, Artificial Intelligence, and Digital Humanities methods to Bengali language and literary texts.

1. NLP – Bengali Stop Words

This project contains a sample collection of Bengali stop words for Natural Language Processing. These words can be used during text preprocessing and linguistic analysis.

View Bengali Stop Words Python File

Status: Completed

2. Extraction of Indian Cultural Elements Using RAG

This section will present the extraction of Indian flora and fauna from Bengali literary texts using Retrieval-Augmented Generation (RAG).

Status: Upcoming

3. Synthetic Reading

This section will present the analysis of a Bengali short story through partial reading, AI-based theme extraction, visualisation, and literary interpretation.

Status: Upcoming

4. Creating a Skill for an LLM

This section will contain a reusable skill developed for a Large Language Model using Markdown instructions.
